# Plan with constraints

1. List every constraint the user gave as a short checklist, correcting typos silently.
2. State assumptions for anything missing, in one line each.
3. Give the plan as a table (for example one row per day with morning, afternoon, evening, travel note).
4. End with a check: for each constraint, say how the plan meets it, or where it could not and why.
5. Never invent opening hours, prices or availability. Say what to verify, or use search results when available.
