# Security

This site is a static demo with no accounts and no stored visitor data. The only server code is `api/ask.js`, which relays questions to Groq.

To report a problem, open a private report under the repository's **Security → Report a vulnerability** tab, or contact the owner on GitHub. Please do not post details in a public issue.

Keys and tokens are never stored in this repository. `GROQ_API_KEY` lives only in the Vercel project settings.
