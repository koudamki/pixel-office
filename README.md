# pixel-office

A public, open-source, illustrated office simulation frontend.

This repository provides a lightweight browser-based office scene that can run as a standalone demo or be embedded into a larger simulation.

## Features

- Isometric illustrated office canvas
- Clickable objects and agents
- Agent movement between work and break spots
- Simple popup and bubble interactions
- CDN fallback for illustrations
- Public-safe, MIT-licensed project structure

## Run locally

From the repository root:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/public/
```
